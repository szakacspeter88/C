##a scanf két bemeneti paraméterrel(argument) rendelkezik
## - formátum sztring
## - memória cim

a % karakter azt jelöli, hogy ez egy formátum, ha ezt a jelet % látod, akkor lehet a % jel után a következő formátumjelölő karakter még   
Integer: %d mint "Digit" vagy %i mint "Integer"  
Float vagy Double: %f mint "Float", vagy float "duplázva": két float regiszter egyben -> Double   
Char: %c mint character   
String: %s az egy karakter array (char nev[20];)   
Pointer: %p cimet ir ki ( printf("%p", &nev); )
